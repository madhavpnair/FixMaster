# FixMaster
## Autonomous CI/CD Remedial Pipeline for GitHub based repositories
- The AI agent analyzes the entire repository after each push (GitHub webhooks help for this) and fixes security threats, bugs, failed builds etc.
- Fine-tuned LLM (SFT), RAG, MCP etc work under the hood
